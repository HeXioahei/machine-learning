# 总结分析

本次试验我们对三个遥感图像数据集（RSOD、RSCIO、UCAS_AOD）和一个
猫狗类别数据集（cat-dog）以及一个景观类别数据集（construction）用vit模型进行训练。无论对于大数据集还是小数据集，训练效果均不错，而小数据集的训练效果会优于大数据集的训练效果，而且，小模型要优于大模型，不容易过拟合。vit对遥感图像进行识别与分类的效果很不错，准确率基本都在0.9以上。除了看训练的效果，我们也挑选了一些图片用训练出来的模型进行了预测，除了少数特例外，预测效果都很不错。

# 收获

相比于上次，这次队员更多地自己动手去运行代码了，而不是只停留在理论。同时，由于原代码无法读取某些数据集的数据，我们也对数据集读取函数进行了些修改与补充，对数据如何进入模型中进行训练有了进一步的认识。我们也学习到了vit的强大之处，它集合多种模型的思想，包括但不仅限于ResNet和Transformer，使其具有多个优点，比如自注意力机制使它具有更加灵活的输入、更好的可解释性。
