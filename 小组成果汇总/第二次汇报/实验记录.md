# 数据集五

**数据集**：UCAS_AOD

**描述**：飞机和车辆检测，飞机数据集包括600张图像和3210架飞机，车辆数据集包括310张图像和2819辆车辆。

**训练集 : 验证集** = 8 : 2 

**模型以及训练和评估结果**：

1.      Vit-base-patch16-224-in21k：

![image.png](https://youki-1330066034.cos.ap-guangzhou.myqcloud.com/machine-learning/202501051856249.png)


2.      Vit-base-patch32-224-in21k：

![image.png](https://youki-1330066034.cos.ap-guangzhou.myqcloud.com/machine-learning/202501051856534.png)



3.      Vit-large-patch16-224-in21k：

![image.png](https://youki-1330066034.cos.ap-guangzhou.myqcloud.com/machine-learning/202501051857919.png)


4.      Vit-large-patch32-224-in21k：

![image.png](https://youki-1330066034.cos.ap-guangzhou.myqcloud.com/machine-learning/202501051857488.png)

**分析：**

* 训练损失从0.916逐渐降低到0.512左右，表明模型在训练集上的预测误差在逐渐减小。
* 训练准确率从0.635逐渐提高到0.822左右，表明模型在训练集上的性能在逐渐提升。
* 验证损失也从0.780逐渐降低到0.494左右，表明模型在验证集上的预测误差也在逐渐减小。
* 验证准确率从0.717逐渐提高到0.840，但在最后几个周期中略有波动，但整体呈上升趋势，表明模型的泛化能力在逐渐增强。
